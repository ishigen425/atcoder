# 異なるグループから1つずつ選ぶペア数(ペア積の総和)

## 問題の形

グループごとの個数 `c_1, c_2, ..., c_k` があるとき、
**異なるグループから1個ずつ選ぶペア**の数を求めたい。

```
ans = Σ_{i<j} c_i * c_j
```

全ペアをそのまま回すと O(k²) になる。これを O(k) で求める。

例:`A=2, B=3, C=1`

- A–B: 2×3 = 6
- A–C: 2×1 = 2
- B–C: 3×1 = 3
- 合計 **11**

## 方法1: 累積和で足していく(おすすめ)

これまで見たグループの合計 `acc` を持っておき、今のグループの各要素と
**前のグループたちの要素**をペアにする。ペアは「後から来た方」で1回ずつ数えるので、
重複も漏れもない。

```python
ans = 0
acc = 0
for c in counts:
    ans += acc * c
    acc += c
```

| 処理 | acc(前) | 加算 | ans |
|------|---------|------|-----|
| A=2  | 0       | 0×2 = 0 | 0  |
| B=3  | 2       | 2×3 = 6 | 6  |
| C=1  | 5       | 5×1 = 5 | 11 |

## 方法2: (S² − Σc²) / 2

`S = Σ c_i` とすると、展開は次のようになる。

```
(c_1 + c_2 + ... + c_k)² = Σ c_i²  +  2 Σ_{i<j} c_i c_j
                           ~~~~~~      ~~~~~~~~~~~~~~~~~
                          同じグループ   欲しいもの × 2
```

よって

```
Σ_{i<j} c_i c_j = (S² − Σ c_i²) / 2
```

例:`(6² − (4 + 9 + 1)) / 2 = 22 / 2 = 11`

```python
s = sum(counts)
sq = sum(c * c for c in counts)
ans = (s * s - sq) // 2   # 必ず割り切れる
```

※ mod を取る場合は `// 2` ではなく 2 の逆元を掛ける。
mod を取るなら方法1のほうが楽。

## よくある間違い

- **総積 `Π c_i`** は「k個のグループから1個ずつ選ぶ **k個組**」の数で、ペアの数ではない。
  k=2 のときだけたまたま一致するので、サンプルが通ってしまいやすい。
- `C(S, 2)` は同じグループどうしのペアも含んでしまう。
  `C(S, 2) − Σ C(c_i, 2)` なら正しく、これは方法2と同じ式になる。

## 使った問題

- ABC482 E - Diameter Endpoint Colors
  - 木の中心から見て、各枝の「中心から距離 = 半径」の頂点を色ごとに数える。
    直径の両端は必ず異なる枝にあるので、色ごとにこのペア数を足せば答えになる。
  - 中心の次数が3以上(スターグラフなど)のときに総積で書くと WA になる。
